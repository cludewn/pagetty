# 表示データの受け渡し

Issue #1と#2は `github.com/cludewn/pagetty/internal/display` の
`Document` を共有する。このパッケージは型と実行可能な利用例のみを含む。

## 責務

- Issue #1：PTY/ConPTY出力を解釈し、スクロールバックと最終画面を表示順に一度ずつ
  `Document.Rows` に格納する。CR上書き、改行、カーソル移動、消去、タブ、折り返し、
  全角・結合文字の幅、SGR属性の継続とリセットはここで解決する。入力は端末エコーに
  現れたものだけを含める。上書き前の時系列画面は含めない。
- Issue #2：受け取った物理表示行を数え、空行付近で分割し、PNG/SVGへ描画する。
  行を再折り返しせず、セルの `Width` を使う。任意の行からページを開始できる。
  生のPTYストリームを再解析しない。Freeze向けのSGR生成は描画用の変換であり、
  元の端末制御の再実行ではない。

## 表現と不変条件

- `Columns` は記録時の正の端末列数。各行の `Cell.Width` の合計はそれ以下。
  この境界は同じ列数で解釈済みのスナップショットを扱う。
  リサイズ時の再折り返しや過去行の幅変更の方針は今回確定しない。
- セルの並び、全角・結合文字、表示幅の規則は `Row`・`Cell` のGoDocを参照。
- `Text` に改行・CR・タブ・ESCなどの制御文字を含めない。表示位置に必要な空白、
  背景色のある空白、消去後に属性が残る空白は明示的なスペースセルで表す。
  省略された行末の列は標準属性の空白として補える。背景色を持つ末尾を削らない。
- `Rows == nil` / 長さ0は表示内容なし。`Row{}` 一つは空の表示行一つ。
  起動時の未使用画面領域で埋めず、出力由来の空行を保持する。
  最終行に改行がなくても通常の表示行として含める。
- 各セルの属性と色指定は `Style`・`Color` のGoDocを参照。標準色と黒は区別する。
  基本属性は前景・背景色、太字、淡色、斜体、下線、取消線、反転。
  点滅等の追加属性、ハイパーリンク、カーソル、代替画面の履歴はこの形式の対象外。
- 受け渡し後は読み取り専用。スライスの共有はディープコピーではないため、記録側と
  描画側が同時に変更しない。プロセス終了状態・中断理由はこの表示形式に混ぜない。
  型はGo内の受け渡し用であり、永続化形式や実行時バリデーターは定義しない。

`example_test.go` は上書き後の内容、空行、全角・結合文字、ページ境界の属性、
背景色付きの末尾空白を示す固定データの利用例であり、端末解析のテストではない。

## ANSI文字列を共有形式にしない理由とFreezeの確認範囲

ANSI文字列だけでは幅と位置が暗黙的になり、行の切り出しにSGR状態の復元が必要になる。
解釈済みの文字・列幅・完全な属性なら、画像側で端末解析や幅判定を重複させずに済む。
セル配列は同じ属性の文字列ランより細かいが、全角・結合文字の境界と空白の属性を明示できる。

Freezeの調査対象は2026-11-20時点のmain
`65acb1e1daed1e6f6989496e15a803b256fdda3a` の一次ソース。

- [main.go](https://github.com/charmbracelet/freeze/blob/65acb1e1daed1e6f6989496e15a803b256fdda3a/main.go)：
  ANSI指定入力を読み、任意の再折り返し処理とANSI用描画処理を持つ。
- [ansi.go](https://github.com/charmbracelet/freeze/blob/65acb1e1daed1e6f6989496e15a803b256fdda3a/ansi.go)：
  CSIの描画処理はSGRのみ。太字のSVG属性設定はコメントアウトされ、淡色・反転の
  処理はなく、全角文字には独自の配置補正がある。端末エミュレーターの代用にはしない。

Issue #2では、解釈済みセルからページごとに完全なSGR属性と改行を生成して渡す方法を
最初に実測できる。再折り返しを無効にし、パレット・標準色・背景・属性の継続を検証する。
この調査はソース確認のみで、Freeze実行、日本語の描画位置、全属性の再現、PNG/SVGの
実動作や配布の成立性を保証しない。制約は再現例とともに報告し、属性を黙って捨てない。
